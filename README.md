# Caça aos Cristais

Jogo escolar para praticar coordenadas do 1º ao 5º ano. Cada toque em uma seta move o robô uma casa ou, a partir do 3º ano, ataca o monstro vizinho naquela direção. O par indica primeiro a coluna e depois a linha.

Abra `dist/index.html` no navegador para jogar localmente. No celular, use as setas da tela. O menu permite escolher do 1º ao 5º ano, com dez fases por série.

Antes de entregar o aparelho ao aluno, escolha a série e cadastre o PIN do professor. O menu passa a liberar apenas a série configurada. Use **Trocar série** com o PIN para mudar a turma. A configuração e o progresso ficam no navegador utilizado.

Os efeitos de passos, cristais, combate, armadilhas e vitória são sintetizados no navegador. O botão de som fica no menu e na tela de jogo e mantém a preferência no aparelho.

## Publicação

Envie a pasta do projeto para um repositório no GitHub e importe o repositório no Netlify. O arquivo `netlify.toml` indica a pasta `dist` para publicação. O protótipo usa HTML, CSS e JavaScript e pode ser publicado sem etapa de build.
